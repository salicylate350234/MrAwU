# 引擎契约：自研 Verlet 为主，planck 只做输出前自检

> 从 `SKILL.md` 移出（原文逐字保留）。什么时候读：迁移/新增受力律、怀疑自研路径的受力分支写错、
> 或需要解释"为什么残差不再是独立验证"时。

### 4b. 引擎策略：**全部由自研 Verlet 计算，planck 只做输出前自检**（现行默认）

**默认构建就是 Verlet，不打包 planck**（`--engine planck` 才会打成对照版）。

```
node node/build.mjs --title "题名" --models plankPush --out "dist/题名.html"     # 默认轻量版
node node/compare-engines.cjs                                                    # 输出前自检：planck 当参照
node node/package.mjs                                                            # 打包流程里已内建这道自检闸门
```

`compare-engines.cjs` 的判据：
- **主判据**：verlet 必须通过该模型**全部**「解析值 vs 仿真值」对照项（逐模型、逐参数组合）；
- **副判据**：末态与 planck 一致（位置 5 cm 或行程 1%、速度 2%，允许 ±5 帧相位差——周期运动对微小周期差极敏感）；
- 同时打印 **planck 自己的误差**，便于判断两个引擎谁更可信（厘米级题上 planck 常明显更差）。

已验证：**14 个模型 / 20 组参数组合全部通过**。

| 受力律类型 | 模型 | 关键机制 |
|---|---|---|
| 板-块摩擦（双接触面） | plank, plankSmooth, plankPush | `boardBlockLaws`：滑动/相对静止/地面静摩擦三分支 + 共速事件 |
| 重力 + 地面 | freefall, projectile | `groundBallLaws`（在 `lib/models/shared.js`）：落地事件 + 位置投影 |
| 斜面约束 | incline, inclinePush | 法向力取解析值使垂直分量精确抵消（无需速度投影）+ 只修位置的投影消漂移 |
| 带面摩擦 | belt | 相对带面速度定摩擦方向 + 共速事件 |
| 绳/滑轮约束 | connector, atwood | **按质量加权**的约束投影（等权投影会给出零运动！） |
| 杆约束 | circular | 双面杆投影（位置拉回圆周 + 去径向速度），张力由投影响量给出 |
| 事件冲量 | collision | 接触时刻解析求解 + 恢复系数冲量（记在 normal 名下） |
| 静力 | balance | 直接给重力 + 两绳张力，净力为 0；`jointItems` 供张力探针读取 |

**迁移一个新模型的步骤**：
1. 写受力律 `xxxLaws(p)`：`force(t,S)` 给出每步各刚体的力分解（与 planck 路径同构的六个分项）；
   可选 `nextEvent(t,S)`（解析给出下一个临界时刻）、`onEvent(t,S)`（临界点改状态，返回 `{body:{part}}` 指明冲量归属）、
   `project(t,S)`（约束投影，同样返回冲量归属）、`lock(S)`（子步内锁定受力分支）、`jointItems(t,S)`（绳/杆张力显示）。
2. 场景里挂 `laws: xxxLaws(p)`。
3. `node node/compare-engines.cjs --model <id>` 必须全绿才能交付。

**六个实测踩出来的坑**（代码注释里都写了）：

| 坑 | 现象 | 正确做法 |
|---|---|---|
| 支持力写成地面托板的 (m+M)g | 竖直净剩 mg，木板 4 s 飞 53 m | 取**净接触支持力**：无竖直加速度时 `normal = mg` |
| 力按子步**端点**取 | 撤力那步少算 ½Fh 冲量 → v 差 0.009 m/s | 力按**子步中点时刻**取 |
| 共速只判 `v_rel == 0` | 事件抖动 13 次、切换时刻磨偏 0.0014 s | 用相对速度容差捕捉（≤5 mm/s 即视为共速并投影） |
| 因子步内分支翻转 | 预测点越过共速点时 F2 换分支 → 该步平均加速度只剩一半 | `lock(S)` 在子步开始时锁定分支 |
| **事件正好落在子步边界** | `onEvent` 永不触发（碰撞冲量从未施加） | 判据写成"事件 ≤ 子步末"就施加，而不是"严格在步内" |
| **等权位置投影** | Atwood 两个物块被一起拉回原处，加速度 0（误差 100%） | 约束修正量按 **1/m 加权**分配 |
| 投影/事件改速度不记账 | 残差飙到 7.69% | 用 `bookDelta()` 把状态改动记成对应分项的冲量 |

**残差的含义变了**：自研路径的 `ΣJ − Δp` 由构造保证一致，**不再构成独立验证**；
物理正确性由 `compare-engines.cjs`（对解析解 + 对 planck）保证。
