# 从题图到动画：识图与建模流程

这份文档是给"执行识图的那个模型"看的操作规范，核心原则一句话：
**图里能量测的只用来定比值，图里没写的数值必须问用户或明确声明为默认值，绝不默默假设。**

## 第一步：看图，写出量测表

用 `read_image` 看图后，**先把下面这张表写出来**再动手建模：

| 量 | 图中是否有标注 | 你量到/读到的 | 采用值 | 依据 |
|---|---|---|---|---|
| 场景类型 | — | 斜面 + 水平推力 | — | 图形拓扑 |
| 倾角 θ | 有（37°） | 37° | 37° | 图中标注 |
| 质量 m | 有 | 2 kg | 2 kg | 图中标注 |
| 摩擦因数 μ | 有 | 0.5 | 0.5 | 图中标注 |
| 外力 F | 有（50 N） | 50 N，方向？ | 向右 | **需要判定方向**（见下） |
| 初速度 | 无 | — | 0 | 默认由静止开始 |

像素量测只用来判断**拓扑与比值**：谁在斜面上、绳子连到哪、箭头指向哪一侧、角度大约多少。
绝对数值一律以图中标注为准；没有标注的（初速度、时长、重力加速度）用默认值并声明。

## 第二步：把"箭头方向"当成一等公民

受力图最容易读错的就是方向，而方向错了整个模型就废了。**用外法向做符号校验**：

设斜面沿 `s` 方向（沿斜面向上），外法向 `n`（垂直于斜面、指向物块被支撑的那一侧）。
对任何一个力，分别算 `F·s` 与 `F·n`：

- `F·n < 0` → 这个力把物块**压向**斜面（支持力 N 变大）
- `F·n > 0` → 这个力把物块**推离**斜面（N 变小，极端情况物块直接飞出去）
- `F·s > 0` → 沿斜面**向上**推

### 实战例子（本题真的踩过）

题图：倾角 37°、m = 2 kg、μ = 0.5，水平推力 F = 50 N。

一开始我把箭头读成"向左推，压向斜面"，写出 `N = mgcosθ − Fsinθ`。
仿真结果 `N = 0`、物块做纯抛体运动。**引擎是对的，我的符号错了**：

斜面外法向是 `n = (−sinθ, cosθ) = (−0.6, 0.8)`（朝左上）。
水平向左的力 `F = (−50, 0)` 与它点乘得 `+30`——**正号意味着这个力把物块推离斜面**，
沿法向的平衡方程会解出 `N = −14 N`，物理上不可能，所以物块必然离开斜面。

向右推（`F = (+50, 0)`）才压向斜面：`F·n = −30`，于是

```
N = mgcosθ + Fsinθ = 20×0.7986 + 50×0.6018 = 46.06 N
```

**结论**：不要凭"看起来像压着"下结论，永远用 `F·n` 的符号判断。
模型里也应该有这一层校验——本项目的 `inclinePush` 在 `N ≤ 0` 时直接抛错，
明确告诉用户"该推力会把物块推离斜面，本题不成立"，而不是算出一堆看起来正常的错数据。

## 第三步：选模型 or 新建模型

优先用现成模型（改动越小越可靠），用 `node node/sim.mjs --list` 看清单。
图里的场景不在清单里时，按 `SKILL.md` 的「新增模型契约」加一个，要点：

1. **参数化**：图上所有的可变数值都做成 `params`，这样 HTML 里会有滑杆，老师能现场改题。
2. **几何自适应**：静态几何给足长度（取景会自动裁到轨迹上），
   或者按解析行程反推必需长度与时长上限——绝不能让物块滑出斜面/带面/木板。
3. **写出 `expect()`**：把你手算的解析解连同测量探针一起写进去。
   这一步不是装饰，它是"动画有没有算错"的唯一机器证据。
4. **采样窗口要避开物理已结束的阶段**（已经落地、已经共速、已经静止），
   否则区间平均值对不上解析解。

## 第四步：验证 → 出图 → 目视

```pwsh
& $NODE node\sim.mjs --model <id>          # 看残差（应 < 0.5%）与对照表（应全 PASS）
& $NODE node\tests.mjs                     # 全库回归
& $NODE node\qa.mjs --model <id> --times 0.2,1.0,2.0
# 然后用 read_image 看生成的 PNG，确认箭头方向、有没有被裁掉、标签有没有叠在一起
```

数值全对但图看不成，同样不能交付——`qa.mjs` 用的是与 HTML 完全相同的 `lib/draw.js`，
所以"我看到的就是老师看到的"。

## 第五步：交付

```pwsh
& $NODE node\build.mjs --title "题目名称"
# → dist/阿物先生.html（单文件，双击可用，含全部模型与新模型）
```

把 HTML 交给用户，并告诉他：一个文件发给任何老师，双击就能用，不需要 node、不需要联网。
他打开后可以在下拉框里选到新模型，拖动滑杆改题重算，右下角能当场看到解析值与仿真值的对照。

## 写题图时的建议（如果图是你自己画的）

- 把已知量（m、μ、F、θ）**直接写在图上**，比让识图去猜可靠得多。
- 箭头画清方向，且**沿着作用线**画，不要为了好看挪位置。
- 标注参考系：斜面倾角标在斜面与水平面之间。
