# 标准工作流（量测 → 选题型 → 建模 → 验证 → 构建 → 交付）

> 从 `SKILL.md` 移出（原文逐字保留）。什么时候读：真正动手做题时。
> 本文件是"流程与判据"；引擎策略见 `engine-contract.md`，场与组合见 `field-and-compose.md`，渲染与受力小窗见 `view-ui.md`。

## 标准工作流

### 1. 读图并量测

用 `read_image` 看图，然后**明确列出你量到的量**，不要默默假设：

| 量 | 你量到的 | 采用值 | 依据 |
|---|---|---|---|
| 斜面倾角 θ | 约 30° | 30° | 图中标注 / 像素量测 |
| 物块质量 m | 未标注 | 2 kg | 题目文字 / 默认值 |
| 摩擦因数 μ | 未标注 | 0.2 | 题目文字 / 默认值 |

图中没有的量必须问用户或明确声明用了默认值。像素量测只用来定**比值**（角度、长度比），
绝对长度必须靠题目给的数字或用户确认。

### 2. 选模型或新建场景

先用现成模型（改动越小越可靠）：

```
node node/sim.mjs --list
node node/sim.mjs --model incline --params "{\"theta\":37,\"mu\":0.25,\"mass\":5}"
```

现有模型覆盖：斜面滑块、斜面+水平推力、自由落体、传送带、板块（滑块滑上木板）、
板块（对木板施加限时恒力）、连接体（绳+拉力）、滑轮（Atwood）、弹簧振子、平抛与斜抛、
圆周运动（竖直面·杆约束）、碰撞与冲量、三力平衡。

图里的场景不在列表里时，在 `lib/models/` 里新增一个模型，契约见下。

### 3. 无头验证（必做）

```
node node/sim.mjs --model incline --params "{...}"     # 看残差与对照表
node node/tests.mjs                                    # 全库回归，必须 0 失败
```

要求：
- `残差 |ΣJ−Δp|` 最大相对值 < 0.5%（≈100% 说明受力符号/方向错了）
- 解析对照表全部 PASS

对不上时按这个顺序怀疑：probe 投影方向符号 → 采样窗口落在非目标阶段（已经落地/共速/静止）→
几何越界（物块滑出斜面/带面/木板）→ 摩擦或恢复系数没真正生效 → 云梯最后才怀疑引擎。

### 4. 生成动画（**只打包这道题对应的模型**）

```
node node/build.mjs --title "板块模型·拉木板（题图15）" --models plankPush --out "dist/题目名.html"
```

**`--models` 是硬规则，不要省**：交给用户的单文件里**只能有这张照片对应的模型**。
传送带的题就只打包 `belt`，绝不能把斜面、圆周运动等无关模型一起塞进去——
用户打开后点齿轮只能看到这道题该有的模型。
（不带 `--models` 时才生成含全部模型的通用演示器，那是另一个交付物。）
构建自检会打印「模型白名单：plankPush」确认过滤生效。

### 6. 交付

交付前确认 `AI_DISCLOSURE.md` 与 `LICENSE` 已随包发出
（AI 参与情况 / 人工问责 / 会话记录查阅方式；MIT 许可与版权声明）。
版本兼容性（浏览器与 Node 的最低要求、实测环境、schema 兼容策略）写在 `README.md` 第六节，
改动依赖或提高语法下限时**必须同步更新那一节**。

把 `dist/*.html` 作为交付物 `present` 给用户，并告诉他：这一个文件发给任何老师，双击就能用，
不用装 node/python，不用联网。详见 `README.md`。

## 命令速查

```powershell
& $NODE node\quick.mjs --model incline                 # 单模型秒级快问快答（默认 ≤12 行，--brief ≤5 行）
& $NODE node\quick.mjs --model plankPush --params '{"force":20}'
& $NODE node\sim.mjs  --model incline --params '{...}'  # 完整受力表 + 解析对照表
& $NODE node\audit.mjs --brief                          # 受力可见性审计（1 行结论；失败时打详情）
& $NODE node\compare-engines.cjs --brief                # 双引擎对拍（1 行结论；失败时打详情）
```
