# 派发任务模板与纪律（给 AI 助手看的）

> 目的：把"20 分钟才写出第一行"压到"5 分钟出结果"。实测依据见文末。

## 1. 必读（最多三份，先读它们再动手）

1. `references/api-index.md` —— 一页纸契约（模型/laws/力表/场景字段/探针/命令）。
2. `references/engine-contract.md` —— `laws` 六个钩子与六个实测坑。
3. `references/model-contract.md` —— 新增模型与 `expect` 探针。

**禁止通读大文件**：`lib/draw.js`(1350)、`node/solve.mjs`(509)、`lib/sim.js`(370)、
`lib/verlet.js`(305)、`lib/track.js`(>300)。在 `api-index.md` 里定位到"哪一节/哪个函数"，
再 `grep` + 指定行范围读那 20–40 行。**不准先读一遍再想**。

## 2. 时间 / 调用预算（默认写进任务里）

- 默认 **≤10 分钟或 ≤40 次工具调用**，到点停下，交回：**已确认事实 + 当前假设 + 卡住的位置**。
- 为什么：上一轮派一个子代理修一个数值 bug，**前 10 分钟一个字都没写**（17:08 最后一次改动 → 17:18 mtime 仍未变 ✗），
  全部消耗在通读 `verlet.js / sim.js / scene.js` 和两个模型文件去**反推**接口。
  这些契约是可一次性写下来的，读 `api-index.md` 只要 2 分钟。
- 想继续可以再派一轮，但**每一轮都必须产出可复现的数字或文件改动**，不接受"我还在读代码"。

## 3. 失败要响（禁止静默兜底）⚠️

任何"物理上不该出现"的状态**必须抛错并打印状态**，不许钳零、不许跳过、不许吞异常：

- 法向力/张力为负、约束失效（距离超差、几何不相切）、能量漂移超阈、事件重复触发、
  参数导致粒子打在极板上（已有正确写法：`lib/models/combo.js:46` 直接 `throw` 并给出修正建议）。

实证案例：一个字段漏拷被静默吞掉，仿真退化成"自由落体 + 能量 −162 J"，
听起来像物理问题，于是 20 分钟全花在错误的受力方向上 ✗。
**报错信息里必须包含状态快照**（时刻、位置、速度、可疑力分量），让下一个人一眼看出是字段丢了。

## 4. 验证纪律

1. 小步迭代用 `node node/quick.mjs --model <id> [--params '{...}']`（默认输出 ≤12 行）；
2. 交付前才跑全量：`tests.mjs` → `audit.mjs --brief` → `compare-engines.cjs --brief`；
3. 截图（`node node/qa.mjs --model <id> --times ...`）**只留 1–2 张、放在最后**；
4. ⚠️ **不许用"放宽容差"让失败项变绿**。失败项要么查出真因，要么如实留在汇报里。

## 5. 并行纪律

- **同一仓库同一时刻只允许一个会改文件的代理**；只读分析（grep、跑 quick/tests）可以并行。
- "避免冲突"**不等于**"禁止跑测试"：只读验证手段必须留给子代理
  （上一轮用"怕冲突"把子代理的验证手段拿掉了，它只能盲改 ✗）。
- 明确列出**禁止碰的文件**（别的代理正在改的那些），其余按需只读。

## 6. 交付格式（≤15 行）

必须含：① 改了哪些文件（路径 + 行数变化）；② 实测数字（用例数/通过/失败、关键物理量偏差、残差）；
③ 未解决项与没把握的地方；④ 复现命令。没有数字的汇报视为未完成。

## 7. 可复制骨架（填完直接发）

```text
任务名：
背景/现象（含实测数字）：
允许改的文件（=可写白名单）：
禁止碰的文件（别的代理在改）：
必读：references/api-index.md + <另外 0–2 份>
验收命令与判据：<命令> → <必须出现的数字/全绿条件>
时间预算：≤10 分钟 / ≤40 次工具调用；超时交回"事实+假设+卡点"
汇报格式：≤15 行，含 文件 / 实测数字 / 未解决项 / 复现命令
额外禁令：禁止静默兜底；禁止放宽容差；禁止通读 >300 行文件
```
