# 题型决策树与现有模型清单

> 内容来源：`SKILL.md` 原文逐字保留 + 当前模型清单。什么时候读：拿到题图，要判断"这是已有题型 / 已有组合配方 / 必须新建模型"时。

## 0. 三个问题定路线

1. **是已有题型？** → 用现成模型改参数（`node node/sim.mjs --list`）。改动越小越可靠。
2. **是两个模组首尾相接？** → 用 `compose.chain()` 声明式接口（接口校验/交接记账见 `field-and-compose.md`）。
3. **都不匹配？** → 在 `lib/models/` 新建一个模型：场景契约见 `model-contract.md`，受力律迁移见 `engine-contract.md`。

> 组合题型（例如"物块从斜面滑下 → 平滑进入竖直圆轨道内壁 → 全程处于匀强电场中"）历史耗时约 **20 分钟/题**，
> 四条根因缺口与成本基线见 `optimization-baseline.md`。

## 1. 现有单模型覆盖

现有模型覆盖：斜面滑块、斜面+水平推力、自由落体、传送带、板块（滑块滑上木板）、
板块（对木板施加限时恒力）、连接体（绳+拉力）、滑轮（Atwood）、弹簧振子、平抛与斜抛、
圆周运动（竖直面·杆约束）、碰撞与冲量、三力平衡。

当前完整清单（`node node/sim.mjs --list`，按注册顺序）：

## 2. 组合配方（已有可复用接口）

- **一维链条拼接**：`compose.chain({stages:[...]})`，用于"加速电场→偏转电场""斜面→圆轨道内壁"这类按轴推进的题。
- **场叠加**：`scene.field = { charges:[{x,y,q}], k }` 把点电荷场套在任意场景上（电荷同时是 `overlay` 静态刚体；探针 `fieldAt`/`chargeCount`）。
- **反求临界参数**：`node node/solve.mjs`（"至少多大 / 恰好 / 最小"类题扫描 + 二分 + 复验对照项）。
- 细节与踩坑见 `references/field-and-compose.md`。

## 3. 二维做不了 / 做不忠实的题型

### 二维能做什么、不能做什么（重要）

planck 是 Box2D 的移植，只有平面刚体。以下是"看着能做、其实不忠实"的坑，都实测过：

- **水平面内的匀速圆周运动做不了**：那是俯视图问题，搬到二维侧视图里退化成一条直线
  ——小球在最低点接触地面时切向速度恰好是竖直的，会被地面立刻吃掉（实测球瞬间停住、张力为 0）。
- **转盘上的物块**同理：需要垂直于屏幕的转轴与盘面摩擦耦合，二维接触模型给不出正确的静摩擦。
- **圆轨道内壁**（水流星）需要平滑内壁：内接多边形近似会让小球滚过顶点时"撞台阶"，
  产生虚假冲量（实测残差 3%~10%、最低点支持力只有理论值的 1/5）。要做就得用链形状/单侧边正确处理。
- 竖直面内**杆约束**的圆周运动是二维下忠实且好用的（也是中学最常考的），已提供。
